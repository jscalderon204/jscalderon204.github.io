# Sea Ice Viz Website — project brief

Craft-forward **third** project: a scroll-driven data story about decades of **Arctic sea-ice decline**, built with **D3.js** and JavaScript (originally coursework).

The defining quality is **smoothness**: the visualization redraws continuously, frame by frame, as the reader scrolls — the chart is effectively a function of scroll position, with axes/scales/marks interpolating between states rather than cutting between discrete steps. The engineering of that smoothness is the story. There are **no headline metrics — do not invent any.**

## Source files (this directory)
- `hero_logic.js` — the real scroll-driven rendering code; use it to describe the smoothness honestly.
- `dataviz_proj_overview.md` — project framing.
- `sea-ice-showcase.mp4` — recording of the finished piece; usable as an inline preview/fallback when no live embed is available.
